# project-hub

내 웹 프로젝트들을 한눈에 모아 보여주는 원페이지 허브 사이트.

- 라이브: https://hocheolshin.vercel.app
- 정적 HTML 단일 파일(`index.html`), 빌드 과정 없음
- `master`에 푸시하면 Vercel이 자동 배포

## 프로젝트 카드 추가 방법

`index.html`의 `<main>` 안에는 접근성 이름이 지정된 세 개의 `<section class="project-group">`이 있다.
성격에 맞는 그룹 안에서 카드(`<a class="card">`) 블록을 하나 복사해 내용과 링크를 바꾼다.
새 배너 색이 필요하면 `<style>`에 `.b-*` 그라디언트 클래스를 추가한다.
